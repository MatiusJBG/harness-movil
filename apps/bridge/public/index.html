Controlá Harness desde el teléfono

El agente, las herramientas y la escritura de archivos siguen corriendo en la PC. Este puente expone la interfaz oficial de DeepSeek Harness a tu red Wi-Fi con un emparejamiento propio.

  1. Instalá la CA local una sola vez en el teléfono.
  2. Escaneá el QR o escribí el código que muestra la PC.
  3. Activá la conexión y abrí Harness.

1. Certificado de la PC

La conexión usa HTTPS con una CA local. Instalala una vez en el teléfono; sin esto el navegador mostrará una advertencia de certificado.

Descargar CA (.cer) CA en PEM
Android

Ajustes → Seguridad → Cifrado y credenciales → Instalar un certificado → Certificado de CA → elegí el archivo descargado. Chrome confía en las CA de usuario para navegar.

iPhone / iPad

Safari descarga el perfil → Ajustes → Perfil descargado → Instalar. Luego Ajustes → General → Información → Ajustes de confianza de certificados → activá la CA de Harness Móvil.

2. Emparejar este dispositivo

Pedí el código en la PC: panel http://127.0.0.1:8444/_hm/.

Emparejar un teléfono

Escaneá el QR desde el teléfono o escribí el código en la pantalla de emparejamiento.
